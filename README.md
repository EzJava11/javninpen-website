# Javier Niño — Web Development

Professional website and portfolio for **Javier Niño**, focused on web development and digital solutions for businesses.

## Tech Stack

* Next.js
* TypeScript
* React
* Tailwind CSS
* Vercel

## Features

* Responsive design
* Modern UI
* Performance and SEO focused
* Project showcase
* Contact section

## Development

```bash
npm install
npm run dev
```

The application will be available at `http://localhost:3000`.
